# Kit pour Omni-Oracle

Ce dossier réunit ce que Claude Code doit réutiliser tel quel (tout vient de ton dépôt omni-texte, relevé le 20/11/2026) :

- `assets/logo-omni-systeme.webp` : logo de l'Omni-système (dé à vingt faces violet entouré d'un anneau lumineux).
- `icons/` : icônes de l'application (192, 512, maskable, apple-touch, favicon), faites à partir du logo.
- `manifest.webmanifest` : manifeste prêt (nom « Omni-Oracle », violet nuit).
- `js/config.js` : réglages centraux (nom, version, auteur, contact, lien Omni-système, préfixe de stockage `oracle`).
- `css/themes.css` : thèmes de couleurs de l'écosystème (Omni violet nuit, Sombre, Clair), copiés d'omni-texte.
- `LICENSE` : licence CC BY-NC-ND 4.0 du code, identique dans tous tes dépôts.
- `SOCLE-extrait.md` : les règles communes de l'écosystème, extraites du CLAUDE.md d'omni-texte.

À placer dans le dossier `kit/` du dépôt `omni-oracle`, à côté de `sources/`.
